# Vyapaar Clone

A full-stack Small Business ERP & Accounting application built with React, Node.js, and SQLite.

## Features
- 📄 **Invoicing** - Sales invoices, purchase bills, quotations, delivery challans, credit/debit notes
- 📦 **Inventory Management** - Stock tracking, low-stock alerts, multi-unit support
- 👥 **Parties** - Customer & supplier ledger management
- 💰 **Accounting** - Expenses, payments, bank reconciliation
- 📊 **Reports** - P&L, Daybook, Stock Summary, GST (GSTR-1, GSTR-3B)
- 🇮🇳 **GST Compliant** - Auto CGST/SGST/IGST calculation

## Tech Stack
- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + Recharts
- **Backend**: Node.js + Express + TypeScript
- **Database**: SQLite (via sql.js)
- **State**: Zustand + React Query

## Getting Started

### Backend
```bash
cd backend
npm run dev
```
Runs on http://localhost:5000

### Frontend
```bash
cd frontend
npm run dev
```
Runs on http://localhost:5173
